### Project Description
"Millicount" is  a simple image processing project designed to count the body segments(rings) of a millepede and hopefully the number of its legs from an image. The project uses basic computer vision techniques to identify and count the segments, making the process more faster and convenient than normal counting....

### The Problem (that doesn't exist)
"A millipede rolls on itself to count its legs."

### The Solution (that nobody asked for)
"This project avoids the issue. By counting the number of rings on its body a millipede can calculate the number of legs it has."
